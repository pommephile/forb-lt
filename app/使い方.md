# 命題データベース（Forb-LT 1.8）の使い方

## 起動

`~/Applications/Forb-LT.app` をダブルクリック。Spotlight なら「命題データベース」か「Forb-LT」。
Dock に常駐させるなら、起動中に Dock のアイコンを右クリック →「オプション」→「Dock に追加」。

初回に Gatekeeper の確認が出たら、右クリック →「開く」。

## 3 つの画面

### 1. 一覧（引く）

82 命題と校正表 10 行を検索・絞り込みする画面。

| やりたいこと | 操作 |
|---|---|
| 命題を探す | 検索欄。名前・式・出典・番号のどれでも当たる |
| 階層で絞る | Π₁ / Π₂ / Π¹₂ / 算術外 などのチップ |
| 軸A の状態で絞る | 独立が分かる（6）／上界のみ（17）／下界のみ（1）／未記入（58） |
| 校正表を見る | 左上「校正表」 |
| 引用文をコピー | 詳細の「引用文をコピー」か `c` キー |

### 2. 逆引き（材料を探す）

よく使う切り口を 10 枚のカードにしたもの。押すと該当する命題が並び、行を押せば一覧の詳細に飛ぶ。

- **PA で証明できない**（下界が PA 以上）— Goodstein、PH、グラフマイナー定理、CH など
- **PA で証明できる**（上界が PA 以下）
- **IOpen で証明できない**
- **独立が分かっている**（上下が違い、両方の値がある）— 6 件
- **上界だけ**（独立とは言えない）— 17 件。ここが一番の落とし穴
- **二階の体系での値**（RCA₀ / WKL₀）
- **証人が線形以下**（軸B の上界が F_1 以下）
- **証人が多項式くらい**（F_2 以下）
- **証人が F_ε₀ 級**
- **軸A が未記入**（文献の穴）— 58 件

### 3. 原稿チェック（自分の文を確かめる）

本文を貼って「調べる」を押すと、文ごとに当たる命題を候補として出す。

- 候補には**区間・階層・一致した語**が出る
- その下に「独立が分かっている／上界のみ／下界のみ」の判定が付く
- **危ない書き方を検出する**: 文に「独立」「証明できない」と書いてあるのに、当たった命題が上界しか持っていない場合、オレンジで警告が出る（`[—, EFA]` の命題を「独立」と書くのが典型）
- 同じ文に複数の命題が当たったときは「区間が細かい方を採る」と注記が出る（例: #2 と N2）

例:

```
素数が無限に存在することは IOpen では証明できない。
Goodstein の定理は PA では証明できない。
```

→ N2（`[IOpen, EFA]`）が「独立が分かっている」、#2（`[—, EFA]`）は「上界のみ」で警告、Goodstein は #75 と C1 が「独立が分かっている」。

**断定はしない。** 候補を出して、出典を 1 行確認してから使う前提の道具。

## 詳細画面の読み方

軸A は自動で 4 つの意味に翻訳される。

| 区間 | 意味 |
|---|---|
| `[PA, PA+TI(ε₀)]` | **独立が分かっている**（PA では証明できず、PA+TI(ε₀) で証明できる） |
| `[—, EFA]` | EFA で証明できる。**弱い体系で証明できるかは未確定＝独立とは言えない** |
| `[IOpen, IΔ₀]` | IOpen では証明できない。上界は未確定 |
| `未記入` | 文献の値が未取得 |

軸B は Π₂ の命題にだけある（F_α の区間と Grzegorczyk の区間）。

## キーボード

`/` 検索、`↑` `↓`（`j` `k`）移動、`c` 引用コピー、`Esc` 解除。EN ボタンで UI が英語になる（表の中身は日本語のまま）。

## 版を上げたとき

```
bash ~/math/forb-lt-audit/app/build_app.sh        # release/v1.8 から作り直す
bash ~/math/forb-lt-audit/app/build_app.sh 1.9    # 版表記を変える
```

`build_app.sh` は `release/` を読むだけで、凍結物には触らない。版を上げるときは `build_app.sh` の `REL` も書き換える。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（データ埋め込みの自己完結 1 枚。ブラウザでも開ける） |
| `data.json` | `release/v1.8` から機械で作ったデータ（82 行＋10 行） |
| `make_data.py` | 表 md → data.json |
| `embed_data.py` | data.json → index.html に埋め込む |
| `ForbLT.swift` | ネイティブのウィンドウ（WKWebView） |
| `build_app.sh` | 上の 3 つを回して .app を組み立てる |

## 限界

- 値は 2026-11-06 時点の文献の写し。82 行のうち約 30 行は外部査読で原典一致まで見ていない
- C6（hydra の高さ 3 の固定 τ 版）は未検証、C8 の ATR₀ 下界は未取得
- 原稿チェックの一致は語の照合であって意味解析ではない。候補は必ず自分で選ぶ
- 表は「既知の結果の整理」で、新しい数学の定理は含まない
