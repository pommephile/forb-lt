# 小論「独立性の2型」v2.2

算術の理論 T について、Π₂ 命題 ψ = ∀x∃y φ(x,y) の独立性を 2 型に分ける短い整理。

- **成長型**: ψ の証人 f_ℕ を抑える T の可証全域関数が無い（Goodstein・PH・hydra など）
- **存在型**: f_ℕ ≤ g となる T の可証全域関数 g がある（#3・N1・N2）

補題 1〜4 と、校正表 10 行への適用（成長型 7・存在型 3・判定不能 6）を載せています。**新しい定理の主張ではなく、既知の事実の整理**です。v1 にあった「PA 以上では成長型だけ」という予想は、補題 4 の反例（ψ := ∀x∃y(y=0)、T := IΔ₀）で撤回しました。
