## 1. なぜ v1 に替えるか（v0 の何が壊れていたか）

v0 は「証明の検証データのサイズ」を測った。証明済みの定理の証明は1つの固定された有限対象なので、P3（一様な論法なら O(1)）を当てると**証明済みならほぼ必ず B0** になる。38行中32行が B0 だったのは測定結果ではなく定義の帰結である（査読メモ 2026-10-29 §4-1）。

v1 は測る対象を「証明」から「**命題の証人**」に移す。証人関数の増え方は命題ごとに決まり、文献に上界・下界がある。測る人の裁量が入らない。

## 2. 階層 F_α（本手順で使う値）

| 値 | 目安 | 例 |
|---|---|---|
| `F_0` | 入力に依らない定数 | 証人が定数（例: N1 の y=0）。有限個の例外もここ |
| `F_1` | 線形（多項式は 2 次以上を F_2 の側に置く） | 次の素数 ≤ 2n（Bertrand） |
| `F_2` | 指数 | R(k,k) ≤ 4^k、DFA の部分集合構成 2^n |
| `F_3` | 塔（反復指数） | Shelah の van der Waerden 上界 |
| `F_ω` | Ackermann 級 | PRA で全域と証明できる関数の上限 |
| `F_ε₀` | ε₀ 直下 | Goodstein の長さ、Paris–Harrington の証人 |

**区間で書く**: `[下界, 上界]`。片方しか文献に無ければ空欄（`—`）にする。**推測で埋めない。**

**F_α の引数**: F_α は**自然数 x（入力の符号）の関数**で、ビット長の関数ではない。ビット数 b の入力は x ≈ 2^b に対応する。したがって **b の多項式は log x の多項式で、x の線形以下（F_1 の内側）**。逆に **b について指数的（2^{cb}）なものは x^c で、x の多項式（F_1〜F_2 の区間）**になる。Mahler の Theorem 2 の指数 (m+1)ν log(m+1) は ν について指数的（m ≈ 20·2^{2.5(ν−1)}）なので x の多項式、Fel'dman の指数は ν・log a の多項式なので x の線形以下（#29 の上界 F_1 はこちらによる）。

**F_0 と F_1 の区別**: F_0 は入力に依らない（定数）。F_1 は入力について線形。v6 まで F_0 を「定数」とだけ書いていたため、#2 の「証人は n+1 以上」を F_1 と書く行と混ざった。**証人が入力の関数として書けるなら F_0 ではない。**

### 2.1 Grzegorczyk は行ごとに書く

F_α から E^k への一律の読み替えは**しない**（F_2=指数 は E³ で、E² は多項式なので 2^n は入らない）。表の値は `data.py` の `GRZ_ROW` が唯一の情報源（v6.1 の `data_base.py` を引き継ぐ）で、行ごとに値を書く。**読み替え表を機械的に適用しない。**

## 3. 手順（W1〜W6）

**W1. 階層を確定する。** 命題を冠頭形（量化子の並び）に直す。Π₂ でなければ**対象外**（`B_v1 = —`）。

**W2. 証人を特定する。** ∀x∃y の y は何か（次の素数、Ramsey 数、停止までの段数、etc.）。

**W3. 文献の上界を採る。** 明示的な評価がある定理・補題を出典つきで引く。無ければ空欄。

**W4. 文献の下界を採る。** 「この関数より速くは増えない」型の結果、または「T では全域と証明できない」型の結果（系 (i) の逆向き）。無ければ空欄。

**W5. F_α に落とす。** 線形は `F_1`、2 次以上の多項式は `F_2` の側として区間で書く（例: Linnik の d^L）。塔は `F_3`、Ackermann 級は `F_ω`。

**W6. 参照文献を1行で残す。** 軸Aと同じ文献を見た場合は、**何のために見たか**を書く（例: 「上界のため／階層の確認のため」）。B v1 は文献から写すので、軸Aと完全に伏せることはできない。**伏せられないことを記録で補う。**

## 4. Π₁ の行を対象外にする理由

Π₁ 命題（∀x φ(x)、φ は有限で検査可能）の強さは、証人の増え方では決まらない。証人が存在しないからである。例: Con(PA) は Π₁ だが、いかなる計算可能関数でも「証人の増え方」を持たない。

**したがって RH・Goldbach・Erdős–Straus（いずれも Π₁）は B v1 の対象外**とする。「LT が Π₁ 問題について何を言えるか」は別の問いであり、本ラウンドでは扱わない。

## 7. #28 型の入力は符号で測る

超越性の命題（#28 e・#29 π）は、**入力 x を P の符号（係数と次数）**とする。証人は「|P(e)|>0 を示す精度」で、必要な精度は符号の長さの対数について多項式（線形以下）。**実数を入力にしない。**入力の取り方を変えると値が変わるので、行ごとに入力を明記する。

## 8. Hardy 階層からの換算（H_{ω^α} = F_α）

Cichoń 1983 の式は **Hardy 階層 H_α** で書かれている。表の尺度は **F_α**（Wainer 階層）なので、次の換算を必ず通す。

> **H_{ω^α}(n) ≈ F_α(n)**（同じ fundamental sequence を使うとき、両者は同じ増大度のクラスに入る）

**例（Cichoń 1983 の本文と整合）**: Cichoń は「H_{ω^ω} は Ackermann 関数の一版」と書いている。Ackermann は F_ω の水準なので、**H_{ω^ω} = F_ω**。したがって
- 塔が2段（m < n^n）の停止長の上界 H_{ω^ω} は **F_ω**（F_{ω^ω} ではない）
- 塔が3段（m < n^{n^n}）の上界 H_{ω^{ω^ω}} は **F_{ω^ω}**
- hydra の高さ2の battle の長さ（KP 1982 が「原始再帰でない」と書く）は H_{ω^ω} = **F_ω**、高さ3は **F_{ω^ω}**

**規則**: Hardy の添字をそのまま F の添字にしない。ω^ を1つ外してから F に移す。

## 9. 上限の表（CEIL_CAL）の意味

`data_cal.py` の `CEIL_CAL[T]` は、**「T で全域と証明できない最初の水準」**の `ORDER_B` での添字である（82行の `CEIL` と同じ意味）。

- 判定は「B の下界の添字 **≥** CEIL[T] なら違反」（T が φ を証明するのに、その証人が T で全域と証明できない関数より速く増える、という矛盾）。
- 尺度の外（添字が `len(ORDER_B)`）は「T の上限がこの尺度に無い」を意味する。
- **IΣ_n の上限は F_{ω_n}**（ω_1 = ω、ω_{n+1} = ω^{ω_n}）。つまり IΣ_1 → F_ω、IΣ_2 → F_{ω^ω}、IΣ_3 → F_{ω^ω^ω}。**8段（F_0・F_1・F_2・F_3・F_ω・F_ω^ω・F_ω^ω^ω・F_ε₀）なのは校正表の尺度で、82行の表の尺度は6段（F_0・F_1・F_2・F_3・F_ω・F_ε₀）。** 校正表では IΣ_2 の上限は添字 5、IΣ_3 は 6。
- **上限の表は2つある**（82行の `CEIL` と校正表の `CEIL_CAL`）。尺度が 6段と8段で違うので、片方の添字をもう片方に使い回さない。それぞれ1か所にだけ置き、生成器と検査器の両方が import する。表ごとに写しを作らない（v7 の事故の原因）。
