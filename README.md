# Forb-LT — 命題ごとの証明論的強さ・算術の階層・証人の増え方

**[English](README.en.md)** ／ ブラウザ版: <https://pommephile.github.io/forb-lt/>

82 の命題について、**既知の結果**を 3 つの軸で整理した一覧表です。

| 軸 | 何を書いているか |
|---|---|
| **軸A** | その命題を証明できる体系と、証明できない体系（文献にある区間） |
| **階層** | 命題の冠頭形を式で書き、算術の階層（Π₁・Π₂・Π¹₂ など）に置いたもの |
| **軸B** | Π₂ の命題について、証人の増え方（F_α の区間） |

**この表は新しい数学の主張をしません。** 文献にある結果を写して並べ、どこが未確定かを明示することが目的です。値にはすべて出典が付き、出典の無い欄は空欄にしてあります。

## 表の読み方

軸A の区間は `[下界, 上界]` の形です。

| 区間 | 意味 |
|---|---|
| `[PA, PA+TI(ε₀)]` | PA では証明できず、PA+TI(ε₀) で証明できる（**独立が分かっている**） |
| `[—, EFA]` | EFA で証明できる。弱い体系で証明できるかは未確定（**独立とは言えない**） |
| `[IOpen, IΔ₀]` | IOpen では証明できない。上界は未確定 |
| `未記入` | 文献の値が未取得 |

**`[—, X]` を「独立」と読むのが一番多い誤りです。** 上界だけでは独立は言えません。アプリの原稿チェックはこの型の誤りを検出します。

## アプリ（macOS）

```
cd app
bash build_app.sh          # ~/Applications/Forb-LT.app を作る（swiftc が要る）
open -a ~/Applications/Forb-LT.app
```

Swift（WKWebView）の薄い殻で、中身は `app/index.html` 1 枚です。ブラウザでもそのまま開けます。

- **一覧**: 名前・式・出典で検索、階層と軸A の状態で絞り込み
- **逆引き**: 「PA で証明できない」「独立が分かっている」「上界だけ」など 10 の切り口
- **原稿チェック**: 文章を貼ると当たる命題を候補で出し、**「独立」と書いてよいか**を警告する

## 検証

```
cd table && shasum -a 256 -c SHA256SUMS.published   # 44/44 OK
cd note  && shasum -a 256 -c SHA256SUMS             # 3/3 OK
```

`table/SHA256SUMS` は凍結時のマニフェストです。公開にあたり 2 ファイルのローカルパスを伏せたため、そちらでは 2 件だけ FAILED になります（`table/PUBLISHED.md` に伏せる前と後のハッシュを両方載せてあります）。

表は `table/build_release.sh` で再生成できます（出力は `V=0`、`F=92/92`、`L=0`）。

## 既知の限界

1. **未査読の行**: 82 行のうち、自明化・弱化・量化を具体的に点検したのは約 50 行。残りは通読のみで、原典一致は未検証。
2. **C6（hydra の高さ 3 の固定 τ 版）**: 原典の Remark は全再帰戦略版で、固定 τ への移し替えは未検証。
3. **C8 の ATR₀ 下界**: Simpson 1985 が未取得。
4. 一次資料のうち 5 件（Ketonen–Solovay 1981、Friedman–Robertson–Seymour 1987、Sakamoto–Yokoyama 2007、Simpson 1985、Hájek–Pudlák 第 II 章）は本文未取得。
5. **新しい定理は含みません。** 表は既知の結果の整理で、予測もしません。
